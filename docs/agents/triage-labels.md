# Triage Labels

| 状态角色 | GitHub 标签 | 使用时机 |
| --- | --- | --- |
| 等待评估 | `needs-triage` | 维护者需要判断是否处理及优先级 |
| 等待补充 | `needs-info` | 缺少复现步骤、环境、预期结果或必要背景 |
| Agent 可执行 | `ready-for-agent` | 范围和验收标准明确，Codex 可独立完成 |
| 人工处理 | `ready-for-human` | 需要产品取舍、视觉判断、权限或人工操作 |
| 不处理 | `wontfix` | 已评估并决定不执行 |

同一问题原则上只保留一个当前状态标签。信息或决策变化后替换标签；修复和验证完成后关闭 Issue。

这些名称是工作流约定，不要求预先批量创建标签。需要实际使用时，再按用户授权检查或创建。
